# Property Management route state checklist

Checked on 2026-09-25. This is a source code review and focused unit test record. It is not a live backend or browser acceptance result. Every PM route is behind `PrivateRoute` and the admin or agent `RoleBasedRoute`. `/pm/audit` is admin only. Each route has an error boundary and a route-level lazy loading fallback.

| Route | Loading, error, and empty states found in code | Permission and mutation state found in code | Verification and remaining work |

No mutation. | Uses `currentData` for owner changes. Check response and role behavior with live accounts. |
